# Nikhil — AI/ML Full Stack Developer Portfolio

Personal professional portfolio for Nikhil. Content is based on the attached resume and professional photograph.

## Tech stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React
- ESLint

## Local development

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal (typically `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Environment variables

None required. The contact form is client-side only and is prepared for a future email service. It does not send messages automatically.

## Resume and photo

- Resume download: `public/Nikhil_Resume.pdf`
- Original resume file: `public/Nikhil_Resume.doc`
- Profile photograph: `src/assets/nikhil-profile.webp`
